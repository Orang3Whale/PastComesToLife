# 六视图风格化重贴图基线设计

## 1. 背景

当前流水线已经能跑通：

`单图 -> SF3D -> 单张 InstantStyle 风格图 -> 单视图回贴 -> GLB 可视化`

但现阶段存在两个结构性问题：

- `贴图不正确`：当前回贴逻辑仍然是单张图的近似投影，不具备完整的相机位姿、可见性判断和多视图重投影闭环。
- `贴图不全`：当前 `InstantStyle` 只生成一张风格化前视图，因此只能覆盖局部可见面，无法完成整模型风格化。

本设计的目标不是继续调单视图参数，而是把当前主视角回贴方案升级为一个可工作的多视图风格化重贴图基线。

## 2. 目标与非目标

### 2.1 目标

- 在保持 `SF3D` 几何生成阶段不变的前提下，建立一个 `6-view` 风格化重贴图闭环。
- 让每个可见 texel 的颜色都来自明确的相机投影，而不是世界坐标近似映射。
- 显著改善当前的两个问题：
  - 前视图风格无法正确对应到 mesh 表面
  - 模型大面积区域没有获得风格化覆盖
- 导出稳定、可复现的标准 `GLB` 资产。

### 2.2 非目标

- 第一版不追求 `8-12` 视角或更高采样密度。
- 第一版不引入真正的多视图联合扩散模型。
- 第一版不做 graph-cut、Poisson blending 或全局优化级无缝算法。
- 第一版不承诺完全消除多视角生成带来的纹样漂移。

## 3. 设计结论

采用 `6-view baseline`，将当前单视图回贴替换为：

`SF3D 白模+UV -> 六相机几何采样 -> 六视图受控风格化 -> 多视图回投融合到 UV -> 导出 GLB`

其中：

- `Stage 1` 保持当前 `SF3D` 方案不变。
- `Stage 2` 到 `Stage 5` 形成新的几何与纹理闭环。
- `Stage 4` 和 `Stage 5` 在概念上分开，在工程实现上可以收敛为 `UV-space weighted reprojection + bake/export`。

## 4. 整体流程

### 4.1 Stage 1：几何与 UV 重建

输入：

- 已去背景的单张物体图片

输出：

- 一个白模或可忽略原始材质影响的 `mesh`
- `SF3D` 自动生成的 UV 展开

说明：

- 本阶段已验证通过，暂不修改。
- 本阶段的核心职责是稳定提供后续阶段所需的几何和 UV 拓扑。

### 4.2 Stage 2：六视图空间采样

对白模进行规范化后，在固定坐标系下布置六台虚拟相机，分别对应：

- `+X = front`
- `-X = back`
- `+Y = right`
- `-Y = left`
- `+Z = top`
- `-Z = bottom`

每个视角统一输出：

- `RGB render`
- `Depth map`
- `Normal map`
- `Foreground mask`
- `Camera intrinsics`
- `Camera extrinsics / pose`

说明：

- 所有视角共用同一套对象坐标约定。
- 后续风格化与回投必须复用这套 pose，不能再单独推导另一套投影坐标。

### 4.3 Stage 3：六视图受控风格化

对每个视角分别执行一次受控重绘，输入包括：

- 该视角的 `RGB`
- 该视角的 `Depth`
- 该视角的 `Normal`
- 该视角的 `Mask`
- 同一张风格参考图
- 同一个 prompt
- 同一个 seed 或受控随机策略

实现原则：

- `InstantStyle` 仍然作为单图风格化模块使用。
- 六个视角共享风格参考、prompt、seed 和主要控制强度，以降低跨视角风格漂移。
- `ControlNet` 用于锁定几何结构，`IP-Adapter / InstantStyle` 用于锁定风格特征。

输出：

- 六张几何轮廓对齐的 `stylized view`

### 4.4 Stage 4：多视图回投与接缝融合

本阶段不再做“整张图直接贴回 mesh”，而是以 `UV texel` 为基本处理单位。

对于每个 texel：

1. 先通过 UV 和 mesh 三角面关系求得其对应的 `3D 位置 P` 与 `法线 N`
2. 使用 `Stage 2` 的六组相机参数，将 `P` 分别投影到六个视角
3. 对每个视角进行有效性检查：
   - 投影坐标在图像范围内
   - 位于前景 mask 内
   - 与 depth map 深度一致
   - 当前视角对该点可见
4. 对所有有效视角的颜色样本进行加权融合

推荐权重：

- `w_angle = max(dot(N, V), 0)^p`
- `w_center`：越接近图像中心权重越高
- `w_edge`：越接近 silhouette 边缘权重越低

最终颜色：

`C = sum(w_i * c_i) / sum(w_i)`

无有效样本的 texel：

- 第一版优先回退到 `SF3D` 原始纹理
- 可叠加简单的邻域扩散或 dilation 填洞

说明：

- 第一版不使用 hard switch 单视角选择，避免明显 seam。
- 第一版也不引入全局最优化拼缝算法。

### 4.5 Stage 5：UV 烘焙与资产导出

本阶段只做确定性封装，不引入新的生成逻辑。

输入：

- `Stage 4` 融合后的 UV 纹理结果
- `Stage 1` 的 mesh 与 UV

输出：

- `texture_preview.png`
- `mesh_stylized.glb`
- 导出元数据

说明：

- 不重新做 UV unwrap
- 不在本阶段重新决定风格
- 若 `Stage 4` 已直接生成 UV-space atlas，则本阶段实质上是写盘和标准格式导出

## 5. 为什么这条路线能解决当前问题

### 5.1 解决贴图位置不正确

当前单视图回贴的问题在于缺少真实相机位姿与深度闭环，导致颜色来源和 mesh 表面位置之间只有近似关系。

新设计中，每个颜色样本都来自：

- 明确的相机 pose
- 明确的深度一致性判定
- 明确的可见性筛选

因此“颜色属于哪一块表面”这件事不再靠启发式猜测，而是靠几何投影关系确定。

### 5.2 解决贴图覆盖不全

当前风格化输入只有一张前视图，因此系统最多只能覆盖局部正面。

新设计中，六个方向都会产出对应风格图，再通过多视图融合回投，因此：

- 正面不再是唯一颜色来源
- 侧面、背面、顶部和底部都可以获得独立样本
- 即使第一版仍有少量未覆盖 texel，也会明显优于单视图方案

## 6. 风险与限制

### 6.1 六视图不是最终极方案

`front/back/left/right/top/bottom` 适合作为 baseline，但无法保证复杂凹陷区域、细腿内侧或遮挡深处被完全覆盖。

因此六视图是“足够好且可实现”的第一阶段，而不是最终形态。

### 6.2 跨视角风格一致性仍有风险

即使所有视角都几何对齐，不同 diffusion 结果之间仍可能出现：

- 亮度漂移
- 纹样位置变化
- 笔触不连续

这类问题不能靠更准的相机投影解决，只能通过更强的一致性策略或后续 seam 优化继续改进。

### 6.3 计算成本会明显上升

从单视图升级到六视图后，风格化生成与回投成本都会成倍增加。第一版设计默认接受这一代价，以换取正确性和覆盖度。

## 7. 推荐执行顺序

推荐按以下顺序推进：

1. 固定 `Stage 2` 坐标系与六相机 pose 格式
2. 跑通六视图几何采样输出
3. 将 `Stage 3` 从单张 `stylized.png` 扩展为六张 `stylized views`
4. 实现 `Stage 4` 的 UV-space weighted reprojection
5. 最后收口到 `Stage 5` 的 bake/export

这样做的原因是：

- 几何采样与坐标系是后续所有步骤的公共基础
- 如果先写回投而相机定义未定，后面仍会再次返工

## 8. 验证标准

本设计进入实现后，第一版验收标准定义为：

- 同一输入样例能稳定生成 `6` 张几何对齐的风格图
- 多视图重投影后，viewer 中正面、侧面和背面都能观察到明显风格化区域
- 前视图主结构在最终模型上不再出现明显的整块错贴
- 导出的 `GLB` 能被现有 viewer 直接加载

不将以下内容作为第一版阻塞项：

- 完全无缝的跨视角纹样连续性
- 复杂凹陷区域的 100% 覆盖
- 生成质量达到最终展示级

## 9. 本设计与现有实现的关系

- 当前已实现版本属于“单视图风格图 + 单视图回贴”的技术验证链路。
- 本设计是下一阶段的结构升级路线，不要求保留现有回贴逻辑作为最终方案。
- 现有 `SF3D`、基础 viewer、运行目录组织和总控脚本仍然可以复用。

## 10. 结论

下一阶段不应继续围绕单视图 projector 做局部修补，而应转向 `6-view baseline`：

- 用固定 pose 的六视图几何采样取代单视图近似投影
- 用六张受控风格图取代单张前视图
- 用多视角加权回投取代单图硬贴
- 用 UV-space 融合和确定性导出取代启发式纹理覆盖

这条路线能够系统性解决当前“贴错”和“贴不全”的问题，并为后续进一步提升风格一致性和无缝程度留下明确扩展路径。
